## Описание выбранной уязвимости
**CVE-2018-13379** — критическая уязвимость в ОС FortiOS (шлюзы Fortinet). Она относится к классу **Path Traversal** (обход путей).

* **Суть:** Из-за отсутствия должной фильтрации символов в URL-запросе, злоумышленник может использовать конструкцию `../` для выхода за пределы веб-директории.
* **Цель атаки:** Чтение файла системных сессий `/dev/cmdb/sslvpn_websession`, в котором могут храниться логины и пароли пользователей VPN в открытом виде.
* **Статус:** Исправлено в патчах FortiOS, данный скрипт является учебной имитацией.
